# 프리펫스 — 앱 (freepets-app)

반려동물과 어디를 가든, 문 앞에서 거부당하지 않게.

한국관광공사 반려동물 동반여행 데이터의 모호한 출입 조건을 AI가 우리 아이 기준으로 판별하고, 방문자 리뷰·제보로 그 정보가 스스로 갱신되게 만드는 앱입니다.

> 2026 관광데이터 활용 공모전 ②-2 웹·앱 구현 부문 / 지정과제 6번 출품작

## 시작하기

```bash
npm install
npx expo start
```

터미널에 QR 코드가 뜹니다. **Expo Go** 앱으로 스캔하면 실제 기기에서 바로 실행됩니다. 웹으로 보려면 `w`, iOS 시뮬레이터는 `i`, 안드로이드 에뮬레이터는 `a`를 누르세요.

## 구조

```
src/
├── app/                  Expo Router — 폴더 구조가 곧 화면 경로
│   ├── (tabs)/           홈 · 탐색 · 랭킹 · 반려동물 · 설정
│   ├── facility/[id]     시설 상세 + AI 판별 + 리뷰 + 만족도
│   ├── review/[id]       리뷰 작성
│   └── report/[id]       정보 정정 제보
├── components/           공통 컴포넌트 16개
├── constants/theme.ts    디자인 토큰 (라이트 테마 고정)
├── data/
│   ├── types.ts          도메인 타입 + 친화도·발자국 등급 계산
│   ├── judge.ts          목 판별 로직 (백엔드와 동일한 입출력 계약)
│   └── mock.ts           강릉 시설 10곳 · 리뷰 382건
└── store/app-store.tsx   펫 · 판별 · 리뷰 · 만족도 · 설정 상태
```

## 백엔드 연동 상태

현재는 **목 데이터**로 동작합니다. `data/judge.ts`가 `freepets-docs/docs/03-ai-prompts.md`의 출력 스키마와 같은 계약으로 만들어져 있어, 백엔드가 붙으면 이 함수 호출만 `POST /api/v1/ai/check`로 교체하면 됩니다. 화면 코드는 손대지 않습니다.

> ⚠️ **Claude API 키와 관광공사 서비스키를 앱에 넣으면 안 됩니다.** 앱 번들은 사용자 기기에 내려가므로 키가 그대로 노출됩니다. 반드시 백엔드를 경유해야 합니다.
